## F001 湖政公共服务轴

| 空间卡 | 正典参数 |
|---|---|
| 类别 / 归属 | 功能区 / 北湖政务片区 |
| 中心坐标 | (-0.579, 4.715) km；x东正、y北正 |
| 占地 / 范围面积 | 0.72 km²（72.00公顷） |
| 日常岗位规模 | 4,000人；不是常住人口 |

**位置与规模**：湖政公共服务轴位于钛湖以北略偏西，属于D01北湖政务片区，中心坐标为(-0.579,4.715)。0.72平方公里是跨地块功能覆盖面积，包含道路、广场和绿地，不是建筑面积。建议场景边界以南侧到达街、北侧办公支路和两侧银杏步道识别，西边遇清岚河缓冲地带应退让，不以规整轴线强切河岸；此处不是贴湖的政务码头。
**规划与空间组织**：现状以南北步行轴串联咨询、受理、调解和后台办公，主入口朝南，东西各开日常通勤口。使用楼面约五成用于政务后台，两成用于公开受理，两成容纳法律服务和社会组织，其余为食堂、托育与便民商业。档案箱和餐饮货品由北侧服务院进出，不穿越排队门厅。近期改善是将等候座椅移入檐下并增加预约咨询桌，不扩建仪式性广场。
**外观与辨识细节**：主体为四至八层的横向办公体量，沿轴分成数段，避免组成封闭巨墙。暖灰石材的横缝与深铜竖框交织，首层玻璃后能看见办事桌和公共等候区，后台窗带更密。银杏树间留出可辨识的视线缝隙，树池边缘只在少数位置做坐凳，盲道保持连续。铺地采用浅灰细面石与深灰过街条带，雨后有局部反光而非镜面地坪，晚间仅檐底和入口铜框发出暖光。
**人群与生活节奏**：日常岗位规模为4000人，不代表常住居民。工作人员包括窗口专员、调解员、翻译、保洁和设备维护人员，访客既有企业经办人，也有携带资料的家庭与老人。早间到达潮短而集中，午后法律咨询较多；周末部分便民服务开放，后台楼保持安静。轮椅访客与推车家庭使用同一主入口，不被导向装卸通道。
**关联与地方性**：南面的L001钛湖市民议事厅和东南面的L002钛湖司法服务馆是公共事务链条中的关联地点，不能凭关联关系搬到轴线中心。这里负责把公众诉求整理成可追踪的事务，再交由专业机构处理。每月面向市民的流程说明活动采用可移动展板，办完事的人常在银杏树下核对材料，而不是举行持续不断的庆典。
**图像与视频取景**：相机放在南入口外公共步道，离地1.6米，朝北，使用35毫米焦距。前景是一段平坡与拎文件袋的访客，中景为铜框门廊，远景由层叠办公楼收住，不强求湖面或塔尖。用8秒缓慢前移到树影边缘，保留脚步、树叶和低声交谈。默认晚秋夕照来自255°，因此北向画面的左后侧石墙较亮，摄影机不进入受理窗口拍摄材料。
**锁定项与禁则**：锁定南北步行轴、暖灰石材配深铜竖框、低台阶旁平坡和疏朗银杏广场四项。禁止将办事人流画成阅兵队列，禁止把关联议事厅置于本区正中或补造湖岸。全部图像无水印，门牌只保留真实排版位置，不生成凭空文字。

## F002 法务与城市档案园

| 空间卡 | 正典参数 |
|---|---|
| 类别 / 归属 | 功能区 / 北湖政务片区 |
| 中心坐标 | (0.579, 4.715) km；x东正、y北正 |
| 占地 / 范围面积 | 0.88 km²（88.00公顷） |
| 日常岗位规模 | 4,800人；不是常住人口 |

**位置与规模**：法务与城市档案园属于D01北湖政务片区，在城市北部偏东，中心为(0.579,4.715)。0.88平方公里描述功能覆盖而非建筑楼面，其中道路与院落不另行累加。建议落图边界围绕中心形成东西较长的院群，以南侧阅览街、北侧服务路及东西两端树阵收边；没有法定宗地多边形，不能把外围相邻住宅全部划作档案库区。
**规划与空间组织**：园内以一条开放阅览街连接法律援助、城市资料查询和文书整理中心，公众入口朝西南，工作人员从东侧进入分院。楼面约四成用于档案整理与保存，三成用于法律事务办公，两成用于查询阅览，其余为培训及生活配套。纸质材料在北侧有顶交接院接收，读者携物检查与货车交接不混用空间。院与院之间设置小尺度休息廊，近期只调整老年读者的导览顺序与无障碍桌位，现有库房不向游览动线开放。
**外观与辨识细节**：向街的四至六层阅览楼开深窗洞，后部较厚实的资料楼用暖灰石材与少量竖向窄窗形成稳定块面。深铜框将通透门厅分成细长格，屋顶是藏在浅女儿墙后的平顶，不塑造成司法宫殿。银杏广场分为几个小口袋而非一个巨场，地面嵌有不带文字的铜色方向条。院中低矮石墙围合常绿灌木，夜间阅览窗透出柔和亮度，保存空间不被装饰性泛光照亮。
**人群与生活节奏**：4800人为日常岗位规模，涵盖档案员、修复技师、法务人员、社区咨询人员和后勤职工，不是住在园内的人口。上午常见来查询旧房图纸的家庭，中午培训班与办公人群交错，下午预约阅览最安静。**关联与地方性**：L003城市记忆档案塔位于本区中心以南略偏东，是资料展示与公众记忆的关联地标；L002钛湖司法服务馆在西南方向承担司法服务，两者均不自动落在园区覆盖内。园内的修复与目录整理连接两处服务，旧商埠契据和机械修造时期的图纸可成为公开展览主题，但私人卷宗不得当成可供摄影的道具。
**图像与视频取景**：在西南入口的街角平台架机，离地1.5米，向东北用50毫米拍摄。前景取铜色嵌条和手持空白预约卡的人，中景为低台阶阅览楼，远景是闭合院墙与银杏冠。9秒横移只经过公共檐廊，镜头停在窗外，不穿入保存空间。255°夕阳从摄影机左后侧擦亮石材，可听到翻书、行李轮和门扇缓冲声，不叠加庄严钟声或湖浪。
**锁定项与禁则**：锁定厚实石材院群、铜框深窗、分散银杏口袋广场和北侧有顶交接院。不得绘制全透明档案仓，不把城市记忆档案塔复制成院内中心塔，不展示真实个人文件。图像保持无水印、无凭空文字，所有公众活动止于明确开放的空间。

## F003 钛湖大学开放校园

| 空间卡 | 正典参数 |
|---|---|
| 类别 / 归属 | 功能区 / 东北文教片区 |
| 中心坐标 | (2.303, 4.154) km；x东正、y北正 |
| 占地 / 范围面积 | 0.72 km²（72.00公顷） |
| 日常岗位规模 | 5,300人；不是常住人口 |

**位置与规模**：钛湖大学开放校园位于城市东北，归属D02东北文教片区，中心坐标(2.303,4.154)。0.72平方公里为教学、街道、庭院共同组成的功能覆盖面积，不是大学总建筑面积，也不宣称等于全校宗地。建议场景边界沿南侧开放学街、北侧教学服务路和东西林荫支路闭合，边缘与普通城市街坊接续，不建立环绕全区的纪念性围墙。
**规划与空间组织**：现状将公共课程楼、教师工作室与学生服务围绕数个砖院排列，南口面向城市访客，北侧接教学后勤。楼面约五成供教学及学术办公，两成用于共同学习与讨论，其余分给实验教学、餐饮和学生支持。开放步道贯穿各院，但仪器教室和资料室仍有门禁。送餐、书籍与教学耗材由北院分时配送，访客团在南端集合。近期增设课程间歇遮雨点并改善路口减速，不把尚未落实的跨街连桥写成现状。
**外观与辨识细节**：红褐砖楼多为四至七层，浅灰预制混凝土梁框在院侧露出，砖墙下部有经雨水冲刷的深色带。坡屋面小讲堂与平顶教学楼交错，屋顶轮廓不追求塔尖。高树冠香樟和榉树罩住步道，树下保留自行车停放格，台阶与宽坡道一同进入门厅。街铺用透水砖，教室窗按较窄节奏排列，夜晚部分研讨室亮灯，黑暗内院仍能辨认低位照明。
**人群与生活节奏**：5300人是日常岗位规模，主要包括教职人员、教学辅助、食堂和物业职工，不是学生总数，更不能当作校园常住人口。课间有背包学生、旁听市民和推书车的工作人员，午间街道最热闹，晚上公开讲座散场后逐渐安静。行动不便者沿平坡进入教室。
**关联与地方性**：西南方向的L004钛湖大学中央图书馆是校城知识网络的重要节点，其坐标不等于本覆盖区中心；南面的L005北书科学博物馆承接公众科学活动。校园把人文课程、教育研究和城市公开课连接起来，食堂窗边也能见到退休旁听者与学生共同讨论。讲座日的折叠坐凳与自行车临时停放管理比宏大校庆布景更具日常辨识度。
**图像与视频取景**：相机位于南侧学街，离地1.7米朝北，用28毫米纳入砖院入口。前景是停放整齐的自行车和黄色落叶，中景有人穿过混凝土门廊，远景以高树冠与教学楼封闭。8秒沿步道平移，录下车铃、翻页和课间交谈；不飞越教室，不拍清屏幕。默认255°夕阳由画面左后侧进入，湖面在相机身后较远方向，不能塞到北向院落尽端。
**锁定项与禁则**：保留红褐砖与浅灰梁框、相连而不全封闭的教学内院、高树冠自行车步道以及平坡门厅。禁止把开放校园写成无边界实验基地，禁止将中央图书馆挪入中庭或把岗位数当学生数。图像无水印，无凭空校训与招牌文字。

## F004 北书公共教育园

| 空间卡 | 正典参数 |
|---|---|
| 类别 / 归属 | 功能区 / 东北文教片区 |
| 中心坐标 | (3.239, 3.474) km；x东正、y北正 |
| 占地 / 范围面积 | 0.88 km²（88.00公顷） |
| 日常岗位规模 | 6,100人；不是常住人口 |

**位置与规模**：北书公共教育园在东北文教片区D02的东南侧功能位置，仍处湖心东北方向，中心(3.239,3.474)。覆盖面积0.88平方公里含道路、教学地块与公共庭院，不是楼面面积。建议落图以西侧公共到达街、东侧后勤巷及南北两条树荫路为场景边界，教学院群围绕坐标锚分布，不把片区的大学及博物馆一并吞入同一围墙。
**规划与空间组织**：这里的重点是终身教育而非另一所封闭大学。南向主门进入课程咨询庭，夜校、教师培训、社区阅读和动手课堂围绕东西向通廊展开。使用楼面中，课程教室与培训办公约占六成，共享阅读两成，展教及餐饮配套各一成。教学物料从东侧独立卸货口送达，亲子团与夜校学员走西南步行口。现有共享会议室按时间开放，近期改善着重给晚课散场路段增加有遮蔽的候车座位。
**外观与辨识细节**：三至六层红褐砖条楼以短边面街，浅灰预制混凝土外廊在端部形成露台，首层架空段能看到后院树干。屋顶以浅坡与平顶交替，创作教室有朝北高窗，不把所有屋面做成同样的玻璃棚。内院栽高冠榉树，矮花池留出儿童等候空间；砖地上嵌浅色无障碍引导带。晚课的暖窗逐间点亮，街道并无连续炫目屏幕，雨棚边滴水也应被排水槽接住。
**人群与生活节奏**：日常岗位为6100人，包括教师、课程开发、教具维护、阅读推广和生活服务岗位，不是园内居住人数。白天有教师研修团和亲子课程，傍晚出现下班后来学语言、电脑与手工技能的成年人。清洁人员的收尾时间晚于课程结束，休息室不能被画成仓库。儿童与成人活动分院安排，扶手高度和可移动桌面兼顾不同身高及轮椅使用者。
**关联与地方性**：L005北书科学博物馆在西南方向，为课程提供展教资源；L006湖畔青年交流馆位于南偏西，承接青年交流而不是园内宿舍。两处都是坐标独立的关联地点。教具作坊制作可重复使用的模型，教师带着修补过的教具箱来交换课程。
**图像与视频取景**：站在西侧公共街离地1.6米朝东，用35毫米拍一段通廊。近处放带轮教具箱，中景为不同年龄学员在院口分流，远景是混凝土楼梯端墙和树冠。连续7秒随一名工作人员的行进方向缓慢侧移，但不追拍儿童面部。255°夕照位于相机右后侧，浅灰梁框受暖光，东向画面不出现背后的钛湖；环境声为课程铃、木凳轻响和枝叶声。
**锁定项与禁则**：锁定短边面街的砖条楼、浅灰外廊端台、北向高窗教室及晚课暖窗。禁止把社区教育画成全是幼儿的幼儿园，禁止将青年交流馆复制进校园中心。全部图像无水印，不杜撰课程标语，不用光束或全息投影替代现实教具。

## F005 钛心总部金融区

| 空间卡 | 正典参数 |

| 中心坐标 | (4.305, 2.007) km；x东正、y北正 |
| 占地 / 范围面积 | 0.72 km²（72.00公顷） |
| 日常岗位规模 | 6,600人；不是常住人口 |

**位置与规模**：钛心总部金融区位于钛湖东北偏东，所属D03东湖金融片区，中心坐标(4.305,2.007)。0.72平方公里是覆盖多宗办公地块、街道与绿地的功能范围，不是总建筑面积。建议场景边界以东西向商务街及两条南北支路组织，西侧有檐步道只是城市联系方向，并不延伸成湖岸宗地。坐标锚定位办公街网，不用于替代地标坐标。
**规划与空间组织**：现状以几组高低相配的办公楼围合可穿行街坊，南侧是访客到达门廊，北侧布置员工自行车口和物流入口。可使用楼面约六成总部及金融办公，两成审计、法律与信息服务，其余用于会议、餐饮和便利配套。货梯厅与访客电梯厅分开，快递在后街汇集后由内部人员转运；地面出租车短停不侵入步道。近期优化午间步行过街与外卖交接点，不增加封闭式行政大院。
**外观与辨识细节**：普通楼群采用十二至二十八层的直线体量，较高部分仍低于200米，沿街深色裙房维持连续檐口。冷灰低反射玻璃以银钛窄竖肋分割，转角并非整面金色镜幕。顶部平直退台，机械设备藏在同色百叶之后；小广场以浅灰石块、列植榉树和窄草带缓和塔楼尺度。晚间主要由办公窗和檐下灯带构成节奏，空置楼层可以暗着，不把金融繁忙表现成满楼霓虹。
