## R061 杉影山居

|---|---|

| 建筑面积 | 143,100 m² |
| 常住人口 | 3,300人 |
| 设定户数 | 1,347户 |
| 建筑限高 | 18 m |
| 设定容积率 | 0.639 |

**位置与规模**：杉影山居位于湖心北偏西的D11北屏生态片区，中心坐标为(-1.593,8.197)千米。占地0.224平方公里，总建筑面积143100平方米。建议落图边界沿南侧生活支路、北侧林缘缓冲带与东西排水绿带围合，以中心锚组织舒展的院落群，不认作法定宗地。这里属于山前外城，北屏山在更远的北方，住宅既不登上山脊，也不直接临钛湖。
**规划与空间组织**：2013年住区已经建成入住，低层短板楼顺缓坡错排，公共院之间用平缓折线路径相连，不以独栋别墅替代成片住宅容量。南面主入口连接食杂店和托幼用房，西面车口接外围停车带，日常机动车不进入杉树院。公共厨房与健康咨询室面向同一门廊，送货另走背街。雨水花园位于路径下侧，过水口设小桥板。未来改善拟增加连续扶手及落叶清理点，现状镜头不得提前出现新设施。
**外观与辨识细节**：住宅以三至五层小体量组合表达，限高18米，屋顶采用深灰缓坡双坡面，深檐在烟灰石基座上投出水平阴影。耐候木只用于入口内衬与局部阳台侧板，灰黑金属窗框按起居室宽窗、厨房窄窗交替排列。阳台有实心下栏板、晾衣杆和不整齐的花盆，不做通体玻璃度假露台。杉木树冠与低矮山茶围住碎石渗水槽，主路为防滑灰砖，夜晚檐下暖灯只照门口。
**人群与生活节奏**：常住3300人、1347户，是自然教育从业者、普通通勤家庭、商店员工与退休居民共同生活的社区。清晨老人沿缓路活动，年轻父母牵孩子经过门廊，保洁人员清理杉针；午间照护者推轮椅在背风处停留。傍晚购物车与自行车分别归位，少量晚班居民安静穿过院口。周末孩子观察落叶而不闯入林地，住户在厨房外交换家常菜，生活不以游客参观为中心。
**关联与地方性**：同片区关联地标L031北屏自然学校位于本区南偏东方向，教育往来经过城市支路，不能把学校画成院内配楼。山居承接森林门户一带的生活需求，居民参与季节性落叶记录，也有人在完全不同的行业上班。雨后住户将湿伞靠在门廊滴水槽边，老人教孩子区分杉针与阔叶，是比巨型生态标语更具体的地方记忆。
**图像与视频取景**：晚秋黄昏从南入口内侧离地1.6米处朝北拍摄，使用35毫米焦距；前景为有水痕的石基座，中景是推车家庭与木衬门廊，远景收在屋脊后疏林。用8秒沿无障碍路缓推，听脚步、杉针扫地声与轻微谈话。255°西南偏西阳光从画面左侧斜入，不保证透过楼群看到湖面或城市塔楼。
**锁定项与禁则**：锁定低矮深灰双坡屋面、烟灰石基座、木衬门廊、杉树雨水院。禁止满屏独栋豪宅、把排水花园扩成湖岸、超过18米的住宅与全员户外制服。所有图像无水印，无凭空生成的店名或宣传文字。

| 设定户数 | 1,478户 |
| 建筑限高 | 27 m |
| 设定容积率 | 0.61 |

**位置与规模**：北屏护林员社区位于D11北屏生态片区正北外城，中心为(0.0,8.35)千米，占地0.28平方公里，总建筑面积170900平方米。建议场景边界以南侧公交接驳支路、北侧疏林带和两侧住宅路收束，中轴不是贯穿森林的公路。以中心锚向两边分置生活院和安静绿地，场地是城市住宅用地而非森林保护设施。钛湖在遥远南方，本社区不拥有湖岸。
**规划与空间组织**：已入住的住区由短板楼与较低的公共服务翼构成，中心保留一条可通行的树荫巷。主入口朝南，东面车辆入口与食堂卸货口合并管理，西侧小门只接步行支路。诊疗咨询、儿童托管和日常修补铺沿巷分布，院内有便于轮椅转向的停留坪；林地工作器具不在儿童院露天堆放。后续拟改善夜归通道的照明遮光罩，属于未来工程，现状仍以门灯和低位庭灯为主。
**外观与辨识细节**：主体采用三至六层折线板楼，建筑高度不超过27米，长边通过错接拆成可辨的家庭单元。烟灰石墙脚承托浅暖灰抹灰，深色窗框形成窄而规整的竖列，耐候木遮片位于西晒窗外。折坡屋面在入口处伸出深檐，阳台半嵌入墙体，端部留晾晒格栅。中央公共院铺粗面石，外围草沟间种蕨类与常绿灌木，木质长凳有靠背，夜景不照亮整片林冠。
**人群与生活节奏**：3620名常住居民组成1478户，其中有护林相关人员及家属，也有教师、餐饮员工、维修人员、儿童和退休长者。清晨有人提饭盒出门，有人照常送学买菜，不能把全部住户画成同一班次的巡护队。午后老人坐在晒得到太阳的院沿，托管儿童在另一侧画树叶。晚间家庭厨房亮灯，少量晚归者从南巷经过，车铃在住宅入口前便停下，保障倒班居民休息。
**关联与地方性**：L032森林访客中心在本住区南方，是同片区公共服务关联点，不是社区入口亭。住户有人在那里从事讲解或保洁，另一些人乘公交到其他城区工作。公共服务翼里的衣物晾干区与雨靴清洁台来自山前多雨的日常需要，邻里常在雨后交换步道积叶信息；对外开放活动安排在公共院，不把居民住宅组织成供游人观察的职业展览。
**图像与视频取景**：选择东侧公共巷口离地1.5米、朝西的50毫米平视镜头，前景是靠背长凳，中景为牵孩子的住户与折坡门檐，后景由灰墙和树冠封住。连续8秒向北侧移，始终停在公共铺地上，收录饭盒轻碰与扫帚声。黄昏的255°夕阳在前方偏左形成低角度逆光，窗面不过曝，背景不添加湖面。
**锁定项与禁则**：固定折线灰墙楼群、木遮片西窗、深檐树荫巷、带靠背的石院座椅。禁止将生活院画成护林营房、出现满院巡逻车辆或山火奇观；不得超过27米，无水印与凭空文字。

## R063 雨谷花园

| 空间卡 | 正典参数 |
|---|---|

| 中心坐标 | (1.593, 8.197) km；x东正、y北正 |
| 占地 / 范围面积 | 0.336 km²（33.60公顷） |
| 建筑面积 | 201,300 m² |
| 常住人口 | 3,940人 |
| 设定户数 | 1,609户 |
| 建筑限高 | 36 m |
| 设定容积率 | 0.599 |

**位置与规模**：雨谷花园处在D11北屏生态片区北偏东的外城地带，中心(1.593,8.197)千米，占地0.336平方公里，总建筑面积201300平方米。建议落图边界用南侧弧形生活路、北侧树带和东西缓坡支路辨认，围绕中心形成宽浅的绿地谷形，不据名称捏造河流。其水景是雨水设施而非钛湖支湾，住宅与远处北屏山之间仍有城市空间，不能直接贴上高山峭壁。
**规划与空间组织**：现状住宅在中央雨水花园两侧错开，短板楼配少量转角楼，三至七层的组合在36米限高内留出通风间隙。西南为主要步行入口，东侧机动车入外围车库，服务车在南缘短停。社区便利店与活动室位于较高的铺地边，儿童院和老人休息台不设在低洼蓄水区。桥板连接两侧步道而不承接汽车。近期拟增加花园边缘的触觉提示与雨天绕行设施，尚不计入已建成画面。
**外观与辨识细节**：烟灰石护脚随地面缓缓抬升，米灰墙上采用细深灰窗框，客厅横窗上有短雨眉。木色嵌入阳台排列成疏密不同的竖带，衣物可在内凹处晾晒。住宅屋顶是低坡错落屋面，公共活动室用深檐单坡顶朝花园打开。石块浅沟、莎草和耐湿灌木组成雨水路径，主步道是浅灰透水砖，转弯处留整块粗面踏石；夜灯沿安全步道分段点亮，沟底保持暗色。
**人群与生活节奏**：3940人、1609户已在此常住。住户包含自然教育人员、外城服务业家庭、跨区通勤者与退休居民，花园不是研究人员的专属观测站。清晨父母带孩子绕开潮湿草坡，午间送餐员在路边停好车再步行入院；老人可以选择平坦环路。放学后孩子在干燥活动坪玩耍，傍晚买菜者穿过桥板。雨天成年人照看窗外积水退去，夜班住户使用不经过游戏坪的回家路线。
**关联与地方性**：关联地标L033杉谷观鸟塔位于南偏西方向，属于片区自然教育网络，不是雨谷花园内部的观景楼。住户周末可前往参加观察活动，日常院内只记录常见小鸟和季节落叶，不喂食聚鸟制造景观。雨后桥板边留下深浅不同的湿痕，孩子在长者陪伴下比较石沟的水位变化，这种缓慢而重复的邻里活动构成社区辨识度。
**图像与视频取景**：雨后傍晚从花园西侧干燥步道离地1.4米向东拍，采用35毫米焦距。前景是粗面踏石的湿边，中景为穿桥板的采购居民，远景保留内凹阳台与层叠树冠。以7秒沿岸侧缓移，不进入沟内，收录滴水、鞋底与交谈声。若使用255°光源，光从相机后方偏右进入；画面不露钛湖与高塔。
**锁定项与禁则**：锁定宽浅雨水谷、木色内凹阳台、桥板步道、深檐单坡活动室。禁画成贯穿社区的大河、深水泳池或环湖别墅，禁以暴雨灾景代替日常生活；住宅不突破36米，图像无水印无凭空文字。

**位置与规模**：松籽里位于D11北屏生态片区北偏西，中心坐标(-1.803,9.276)千米，属于较外侧的山前居住地。占地0.224平方公里，总建筑面积184700平方米。建议落图边界取南侧社区路、北侧松林退让带和两边折线支路，中心锚对应公共小广场。名称里的松籽来自院落树种，不意味着住宅散落在自然保护林内。这里不临钛湖，山体仅作为北向空间的远层次。
**规划与空间组织**：2013年的成片住宅以三至五层紧凑院落组合承载楼面，总体限高18米，不能用几栋单层木屋表现全区。南侧门口设连续日用品铺面，西南车口通外围停车区，北侧仅留接绿带的步行出口。十字形公共巷将儿童活动院、安静读报院与晾晒院区分，消防通道不被树池堵住。共享储物间位于楼梯入口旁。未来计划整修树根隆起处铺装，现状仍能看见局部修补缝而非崭新整街。
**外观与辨识细节**：烟灰石下墙、暖灰粗抹灰上墙和木褐门廊组成低矮街面，双坡屋顶短段重复，交接处留细天沟。窗框偏深棕，厨房窄窗与家庭客厅的成对方窗可以区分；凸出阳台下有薄混凝土挑板，耐候木栏片只围侧边。院口竖立朴素的石质树池，松树下铺碎石而不是整片人工草坪，地面松果由居民定时清理。夜间店铺暖光低于檐线，住宅上层窗光呈零星分布。
**人群与生活节奏**：常住4260人、1739户，其中多代家庭、独居老人、便利店职员和普通通勤者交织，也有从事山林服务的居民。早晨摊铺备货与学生出门时间相叠，配送只在外围短停。午后老人坐在读报院，照护人员协助居民走过转角坡道；傍晚孩子收起滑板让出主巷。周末居民交换盆栽和旧童书，夜里只有少数归家脚步，不把低层生活区描写成游客全天候逛吃的商业街。
**关联与地方性**：L031北屏自然学校位于更南偏东方向，与松籽里之间还隔着其他城市街坊，不能标成紧邻院墙。学校活动让一些家庭认识松树的季节变化，院内的生活则由食杂铺、照护与通勤共同支撑。松果收集盘只在秋季邻里手作时摆出，之后收回活动室；旧住户会带着孩子检查哪处树池需要清扫，形成不靠宏大纪念物的公共习惯。
**图像与视频取景**：在南侧十字巷入口离地1.6米朝北，用40毫米镜头压住低屋顶尺度。前景是石树池和扫帚，中景为购物家庭与一排阳台，远景是松冠后更淡的山色。连续9秒沿巷推进后停在路口，听松果落石、店内餐具与车铃。黄昏255°光从左侧擦过木栏片，楼体遮挡下不要求看见钛湖。
**锁定项与禁则**：固定低层密集短屋脊、石质松树池、十字公共巷、木栏片挑阳台。禁止孤立小木屋替代住宅容量、把松籽里画成林间露营地或新建空区；严守18米限高，无水印无凭空文字。
