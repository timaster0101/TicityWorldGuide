真源与产物分开放：**手填的源头在 `分卷/原稿/` 与 `数据/*源表.json`，其余都是生成物**。
本目录的生成物一律由 `工具/` 下的脚本产出，不手改。

| 文件 | 内容 |
|---|---|
| `01-外围村镇.json` … `11-居民区第4卷.json` | 11 个分卷的地点骨架（坐标、面积、层数、量级） |
