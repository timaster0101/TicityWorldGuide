**Tech Stack:** Python 3（json／math／statistics／pathlib／unittest），Node 导出 Word 沿用第1期链路。

**Spec:** `设计/2026-10-31-岗位准入字典-design.md`

## Global Constraints

- 基准年 2013，货币钛币 TT，全部内容为虚构设定。
- 生成物永不手改：`数据/岗位准入正典.json`、`数据/岗位准入总表.md`、`数据/产业就业正典.json`、`数据/产业与就业总表.md`、`数据/产业就业核验.json`、`质量核验报告.md`、合订本 md 与 docx、两张 SVG、`阅读入口.md`、分卷成稿。
- ID 前缀固定：`SKL-`、`SCN-`、`CTR-`、`CRD-`、`RLS-`；阶四值 见习／熟练／精通／权威；途径五值 WKS／TRN／LRN／LEV／EVT。
- 第1期卡片既有字段（`用工形态` 五值、`名额`、`月薪带_钛币`、`时薪带_钛币`、`起始城市年`、`占用名额`）一字不改，本期只做加法。
- 数据字段禁现 估值、轮次、股权（C53）与公职授予（C51）；卡牌不得出现资金类效果。
- 不动 264 篇地点正文、名录、定价、提示词与任何图片；`prompt_sha256` 必须实测保持不变。
- 每次批量写中文文件后扫描 U+2026、U+FFFD 与汉字夹小写拉丁，损坏用 heredoc 整段重写。

def build_tags():
    tags = []
    for s in OCC['小类']:
        for kind, spec in SOURCE['专属标签'].items():
            tags.append({'id': 'SKL-' + s['id'] + '-' + kind, '名称': s['名称'] + spec['后缀'],
                         '族': '专属技能', '子类': kind, '父大类': s['父大类'], '父小类': s['id'],
                         '可推进途径': list(spec['途径']), '可由日常活动推进': 'LEV' in spec['途径']})
    for c in SOURCE['通用技能池']:
        tags.append({'id': c['id'], '名称': c['名称'], '族': '通用技能', '子类': None, '父大类': None,
                     '父小类': None, '可推进途径': list(c['途径']), '可由日常活动推进': True})
    for d in OCC['大类']:
        tags.append({'id': 'SKL-Q-' + d['id'], '名称': d['名称'] + SOURCE['资质标签']['后缀'], '族': '资质',
                     '子类': None, '父大类': d['id'], '父小类': None,
