# 运行参数包（第4期）实施计划

> **执行者须先读**：`设计/2026-10-31-运行参数包-design.md`（本期 spec，所有数字与判据以它为准）。
> 逐步用 `- [ ]` 勾选跟踪；每个 Step 是一个动作，测试先行（红→绿），每任务末尾提交一次。

**目标**：把索引「参数类」五项缺口（技能成长与退化阈值、各交通方式固定耗时、天气的画面演进规则、事件冷却与负面配额、检查点频率）落成一组**固定值查表参数**，并顺带收口三项本轮追加裁定（全域鸟瞰采用 v05、开图验收长文本保留、图片资产结构与元数据复验门禁）。

**架构**：唯一人工源表 `数据/运行参数源表.json` → `工具/build_params.py` 派生 `数据/运行参数正典.json`（50 格交通矩阵、365 格天气年历、月→SEA 与 LVL→阈值两张查表）与 `数据/运行参数总表.md` → `工具/verify_occupations.py`（正典门禁）由二十条扩到二十五条 → `工具/negtest_occupations.py` 由 40 例扩到 45 例。参数**不参与**薪酬带与物价计算，故 `build_params.py` 排在 `build_occupations.py` 之后、不前置。

**技术栈**：Python 3.14（仅标准库 `json/math/statistics/pathlib/collections/struct/unittest/subprocess`）、Node 仅用于既有 `export_docx.cjs`。无新增依赖、无随机过程、无逐人模拟、无路网建模。

**Spec**：`设计/2026-10-31-运行参数包-design.md`

## Global Constraints

- 基准年 2013（非闰年，2 月 28 天）、货币钛币（TT）；口径承接既有正典。
- **逻辑尽可能简单**（用户第3期开工指示仍然有效）：全部参数为固定值查表。零随机、零逐人模拟、零路网建模、零逐地天气差异。
- 天气与交通只作画面与叙事条件：不封闭路线、不限流、不改开放状态、不产生费用／状态／进度变化，不改变固定耗时，不降速、不随机延误、不触发改道（大纲 :135—:137、:167—:168）。
- 能力成长须与时间投入、训练与真实使用相符，不得凭叙述直接提高；一张卡不得跨多级（:208、:327）。技能退化属常态时间流逝而非惩罚；离线不额外惩罚、不占配额、不推进冷却与危机（:17、:330、:581）。
- 服务器异常恢复到最近一次已生效账本状态，幂等键保证同一行动不重复结算；**不提供用户自助回档**（:633）。
- 不得因参数需要新增正典设施：名录 264 条里**没有**机场、轮渡、车站类条目，唯一铁路承载体是 `F025 东门铁路综合枢纽区`；大纲 :105 明令不得另造机场与跨湖通道。轮渡／机场／山外接驳一律登记为 `延后方式`，不进矩阵。
- 生成物永不手改：改源表 → 重跑 `build_params.py` → 重跑全链。
- 第1—3期不变量必须逐项复现：公司 1403（具名 1339）、岗位卡 5151、雇员 378140、被顶起 562 张／30869 名额、篮子 3032.7／2790.1／2577.8／2395.8、库存 176 行、户数 669716、人口 1654200、名录 264 条零漂移。
- **禁止任何出图动作**（含四张鸟瞰的重做与新生成）；不得覆盖既有已验收图片；图片结构与元数据核验器只判「文件存在／字节类型／XMP 里的 TC260 与 AIGC 在位」，**不得把结构合规写成视觉验收，不得由脚本代签 `image_prompt_sha256`**。
- 保留平台「Qoder AI生成」角标与图片 XMP 里的 TC260 元数据，不得裁剪、遮盖或修补；第三方台标／渠道 logo 水印仍一律判废。
- 每步落盘中文后必须扫 `U+2026`／`U+FFFD`／汉字夹拉丁；发现损坏整段重写，不做追加式修补。
- 裁定条数由 74 → **81**（C75—C81）。三处硬编码断言必须同批改：`工具/test_costs.py:249`（方法名 `test_rulings_are_74`）、`工具/test_occupations.py:461`、`工具/test_occupations.py:479`。

```python
RINGS = ('内湖环', '外城环', '产业小镇', '特色村落')


def pair_key(a, b):
    """无序圈层对的规范键名，按 RINGS 下标定先后，避免 A|B 与 B|A 两份键。"""
    return f'{a}|{b}' if RINGS.index(a) <= RINGS.index(b) else f'{b}|{a}'


def ring_pair_stats():
    """64 个 F／S 锚点两两直线距离的逐圈层对统计。交通固定耗时由它派生，门禁也按它复核。"""
    coords = {e['id']: e['center_km'] for e in REGISTRY if e['id'][0] in 'FS'}
    buckets = {}
    for key in coords:
        buckets.setdefault(entry_ring(BY_ID[key], BY_ID), []).append(key)
    out = {}
    for i, a in enumerate(RINGS):
        for b in RINGS[i:]:
            ds = []
            for x in buckets[a]:
                for y in buckets[b]:
                    if a != b and x >= y:
                        continue          # 跨圈层只取一份（400／320／160／128）
                    if x == y:
                        continue          # 同圈层保留 (x,y) 与 (y,x) 两份（380／240／56）
                    dx = coords[x][0] - coords[y][0]
                    dy = coords[x][1] - coords[y][1]
                    ds.append(math.hypot(dx, dy))
            med = statistics.median(ds)
            out[f'{a}|{b}'] = {'锚点对数': len(ds), '中位直线km': round(med, 3),
                               '最小km': round(min(ds), 3), '最大km': round(max(ds), 3),
                               '最大偏差km': round(max(abs(d - med) for d in ds), 3)}
    return out
```

**「锚点对数」的计数口径**：同圈层对按有序对计两份、跨圈层对按无序对计一份，这是与 spec §2.2 的 380／400／320／160／240／128／56 逐格对齐的唯一写法（内湖环 20 点若只取 `x < y` 会得 190，与 spec 不符）。中位数、最小、最大与最大偏差都不受重复计数影响，只有这一列展示值受影响。

    """按 marker＋body 拼一段合法 JPEG：size 字段＝2＋body 长度，含 size 自身。

```python
# -*- coding: utf-8 -*-
"""开图图片资产核验：对 数据/开图清单.json 的每个 image_file 判四件事——文件在不在、是不是 JPEG 字节、
APP1 XMP 段在不在、XMP 里 TC260 与 AIGC 标识在不在。

不生成图片、不改图片、不解码像素、不做视觉验收，也不写 status 或绑定 image_prompt_sha256。
跑法：python 工具/verify_image_assets.py [--out-dir DIR]
"""
import argparse
import json
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
XMP_NS = b'http://ns.adobe.com/xap/1.0/'


def sniff(path):
    info = {'存在': False, '字节数': 0, '魔数': '', 'JPEG': False, 'XMP': False,
            'TC260': False, 'AIGC': False, 'C2PA': False, '扩展名': path.suffix.lower()}
    if not path.exists():
        return info
    data = path.read_bytes()
    info.update({'存在': True, '字节数': len(data)})
    info['魔数'] = data[:4].hex()
    info['JPEG'] = data[:3] == b'\xff\xd8\xff'
    pos, payload = 2, b''
    while pos + 4 <= len(data):
        if data[pos] != 0xFF:
            break
        marker = data[pos + 1]
        if marker in (0xD8, 0x01) or 0xD0 <= marker <= 0xD7:
            pos += 2
            continue
        size = int.from_bytes(data[pos + 2:pos + 4], 'big')
        if size < 2 or pos + 2 + size > len(data):
            break
        seg = data[pos + 4:pos + 2 + size]
        if marker == 0xE1 and seg.startswith(XMP_NS):
            info['XMP'] = True
            payload = seg
        if marker == 0xEB:                       # C2PA 用 jumb 盒；实测 1056 格全为 False，缺位属预期
            info['C2PA'] = seg[:4] == b'jumb'
        if marker == 0xDA:                       # 压缩数据开始，元数据只可能在段前
            break
        pos += 2 + size
    if info['XMP']:
        info['TC260'] = b'TC260' in payload
        info['AIGC'] = b'AIGC' in payload or b'aigc' in payload
    return info


def check(items, root=ROOT):
    """返回逐格结论。`失败` 只收四类硬判据；扩展名与字节不符只进提示。"""
    rows, fails, notes = [], [], []
    for it in items:
        for rel in (it.get('image_file') or []):
            info = sniff(root / rel)
            reason = ('文件缺失' if not info['存在'] else
                      '非JPEG字节头' if not info['JPEG'] else
                      '缺XMP段' if not info['XMP'] else
                      'XMP缺TC260标识' if not info['TC260'] else
                      'XMP缺AIGC标识' if not info['AIGC'] else None)
            row = {'id': it['id'], '路径': rel, **info, '判定': '通过' if not reason else '失败'}
            rows.append(row)
            if reason:
                fails.append(dict(row, 原因=reason))
            elif info['扩展名'] not in ('.jpg', '.jpeg'):
                notes.append({'id': it['id'], '路径': rel,
                              '提示': f'扩展名 {info["扩展名"]} 与 JPEG 字节不符，只作提示不判红'})
    return {'文件格数': len(rows), '通过格数': len(rows) - len(fails), '失败格数': len(fails),
            '提示格数': len(notes), 'C2PA在位格数': sum(1 for r in rows if r['C2PA']),
            '失败明细': fails[:40], '失败总数': len(fails), '提示明细': notes[:40],
            '判据': '文件存在＋JPEG 魔数＋APP1 XMP 段＋XMP 内 TC260 与 AIGC 标识四项缺一即判红；'
                    'C2PA（0xEB jumb 盒）实测 1056 格全部缺位，属预期不判红；'
                    '扩展名与字节类型不符只记提示。',
            '提示口径': '图集内 1056 个文件都是 JPEG 字节却带 .png 扩展名（生成器落盘时的命名遗留）。'
                        '本期不改名：改名会同时打乱开图清单、批次记录与既有验收备注的引用。',
            '声明': '结构合规不等于视觉验收。本核验不判构图、不判穿帮、不判水印，'
                    '不得由脚本代签 image_prompt_sha256；人工复验结论只能由人写进验收备注。'}
```
